Giving back

AI Maestro runs fleets of agents every day. When a tool or standard we build on breaks, or lacks something agents need, we fix it or propose it where it lives, not only in our own copy. This is that work, newest first.

Open protocols we publish

AI Maestro is one implementation. The protocols underneath it are open, with their own specifications, sites and reference code, so any agent platform can use them.

AMP Agent Messaging Protocol Signed messages between agents, local or federated. AID Agent Identity An agent proves who it is to an API, with a conformance suite. AAP Agent Actions Protocol Pages an agent shows a person, and what the person does on them. ADP Agent Device Protocol An agent owns and uses real devices: a kiosk, a phone, a camera. AFP Agent Files Protocol Files shared between agents, hosts and people.
